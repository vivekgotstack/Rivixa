# Rivixa carton concepts

Eight original pharmaceutical carton mockups, created with the built-in image generation tool on 23 October 2026. The design uses Rivixa's navy and sky-blue identity, green company descriptor, white cartons and a distinct accent for each variant. Numbers supplied for Progevix and Dydrovix are shown in mg.

These original concepts are retained as design-source references. Unused website exports have been removed; the current product images are listed in the [product catalogue](../../frontend/src/lib/products.json).
